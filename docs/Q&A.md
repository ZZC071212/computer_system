# 常见问题及解答

## 1. 实验提交要求

实验提交时需要提交工程压缩包和实验报告。

实验报告要求上传pdf文件，其中需要包含以下内容：

- 实验原理
- 实验代码实现
- 实验结果分析
- 实验中遇到的问题及解决方法
- 思考题与心得体会
- 对实验指导的建议（可选）

文件命名格式为：`labX_学号.pdf`（第X次实验）。注意：

a. 实验原理需要用自己的话描述，体现自己对实验的理解。

b. 在代码实现一节重点展示设计思路和核心部分代码即可，不需要大段粘贴代码。如要展示代码，需以非纯文本的形式展示（即代码块）。

c. 思考题占有一定的分值，需要认真回答。

## 2. 校网无法正常访问gitee仓库

可能是校网DNS服务器的问题，可以通过用手机热点或开代理的方式解决。若希望一劳永逸，可以修改hosts文件，下面以Windows系统为例进行说明。

进入`C:\Windows\System32\drivers\etc`目录，打开`hosts`文件，在文件末尾添加`153.3.137.123 gitee.com`，保存后运行`ipconfig /flushdns`命令删除DNS缓存内容，即可用校网直接访问gitee仓库。
